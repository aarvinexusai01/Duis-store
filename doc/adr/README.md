# Architecture Decision Records

The summary log is in [02-architecture.md](../02-architecture.md#decision-log). Add a file here when a decision needs more context than one table row: alternatives weighed, a reversal of an earlier decision, or anything a future maintainer would ask "why?" about.

**File name:** `NNNN-short-title.md` (for example `0013-drizzle-1-0-upgrade.md`), numbered to match the ADR ID in the log.

## Template

```markdown
# ADR-NNNN: <decision in a few words>

- Status: Proposed | Accepted | Superseded by ADR-XXXX
- Date: YYYY-MM-DD
- Deciders: <names/roles>

## Context
What problem or constraint forced a decision? Include versions and facts checked.

## Options considered
1. <option> — pros / cons
2. <option> — pros / cons

## Decision
What we chose, in one or two sentences.

## Consequences
What becomes easier, what becomes harder, what we must watch, and when to revisit.
```
